Quero expandir a SNB para que ela não seja limitada aos modelos de IA disponíveis no Puter.

A SNB deve funcionar como uma inteligência universal capaz de utilizar MODELOS DE IA + APIs + SDKs + PLUGINS + SOFTWARES + ENGINES + SITES + CLI + BIBLIOTECAS + SCRIPTS + FERRAMENTAS DIGITAIS e, futuramente, HARDWARE/DISPOSITIVOS, sempre respeitando autorização, segurança, licenças e termos de uso.

O objetivo é que o usuário não precise saber qual ferramenta usar.

O usuário fornece o objetivo.

A SNB descobre COMO realizar esse objetivo.

3. TOOL DISCOVERY ENGINE
==================================================

Criar um sistema que consiga descobrir novas ferramentas.

Quando a SNB recebe uma tarefa:

1. decompor a tarefa;
2. identificar capacidades necessárias;
3. procurar ferramentas capazes;
4. comparar alternativas;
5. verificar compatibilidade;
6. verificar segurança/licença;
7. testar quando necessário;
8. escolher as melhores.

Não depender de uma lista fixa de ferramentas.

Permitir que novas ferramentas sejam descobertas e adicionadas ao ecossistema.

60. IMPLEMENTAÇÃO
==================================================

Antes de criar qualquer coisa:

1. analisar o repositório atual;
2. identificar sistemas existentes;
3. reutilizar o que já existe;
4. evitar duplicação;
5. verificar quais itens da arquitetura V1 já estão implementados;
6. implementar primeiro as fundações;
7. integrar gradualmente;
8. criar testes;
9. conectar ao frontend;
10. documentar;
11. validar com tarefas reais.

Não criar mockups ou funcionalidades falsas apenas para aparentar que o sistema funciona.

Toda funcionalidade apresentada como disponível deve possuir implementação real ou ser claramente marcada como experimental.

Priorizar nesta ordem:

Tool Registry
→ Capability System
→ Policy Engine
→ Sandbox Execution
→ Tool Discovery
→ Competency Map
→ Universal Router
→ Tool Agent
→ Multi-tool Orchestration
→ Pipeline Synthesis
→ Verification
→ Auto-Repair
→ Memory
→ Continuous Benchmarking
→ Community Extensions
→ Physical Intelligence foundations.

A arquitetura deve ser modular para que novos modelos, sites, softwares, APIs, ferramentas e dispositivos possam ser adicionados sem modificar profundamente o núcleo da SNB.

O objetivo não é criar apenas "mais um chatbot".

O objetivo é construir uma infraestrutura de inteligência capaz de transformar diferentes modelos, ferramentas e recursos externos em um sistema único de execução, pesquisa, criação, automação, verificação e aprendizado contínuo.
